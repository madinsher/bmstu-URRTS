# Материалы примера отчёта

Рисунки построены по журналам эталонного прогона этапа 2 (зерно 1, 600 с модельного времени)
скриптом `code/plot_run.py`:

```bash
python3 plot_run.py ~/urrts_logs/stage2_1 --out reports/hw/figures
```

| Файл | Что показывает |
|---|---|
| `figures/orders_stage2_1.png` | жизненный путь каждого заказа: ожидание закрепления (серое) и выполнение (синее) |
| `figures/traj_stage2_1.png` | траектории четырёх роботов за прогон |

Свои журналы прогонов бригада хранит в собственном репозитории (`reports/hw/`), сюда они не копируются.
