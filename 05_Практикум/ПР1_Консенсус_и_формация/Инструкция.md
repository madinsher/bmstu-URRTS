## 1. Справка

**Граф связи.** Роботы — вершины, радиосвязь — рёбра. Матрица смежности A симметрична, aᵢⱼ = 1, если роботы i и j слышат друг друга. Степень вершины dᵢ = Σⱼ aᵢⱼ, D = diag(dᵢ).

**Лапласиан** L = D − A. Свойства (§4.1.3): L симметрична и неотрицательно определена; L·1 = 0, то есть вектор из единиц — собственный с собственным числом 0; число нулевых собственных чисел равно числу компонент связности. Собственные числа упорядочиваются 0 = λ₁ ≤ λ₂ ≤ … ≤ λ_N; **λ₂ > 0 тогда и только тогда, когда граф связен** (Фидлер, 1973).

**Дискретный консенсус** (§4.3.2):

xᵢ(k+1) = xᵢ(k) + ε Σⱼ aᵢⱼ (xⱼ(k) − xᵢ(k)),  то есть  x(k+1) = (I − εL) x(k) = P x(k).

При 0 < ε < 1/Δ_max матрица P стохастическая с положительной диагональю; для связного неориентированного графа все xᵢ сходятся к среднему начальных значений. Среднее сохраняется, потому что 1ᵀP = 1ᵀ. Рассогласование убывает не медленнее ρᵏ, где ρ — второе по модулю собственное число P; для P = I − εL это max(|1 − ελ₂|, |1 − ελ_N|). При малом ε работает оценка ρ = 1 − ελ₂: **число итераций до точности δ ≈ ln δ / ln(1 − ελ₂)**.

**Формация по смещениям** (§4.5.1). Желаемое положение робота относительно общего центра — δᵢ. Замена ξᵢ = pᵢ − δᵢ превращает задачу «встать в фигуру» в задачу «согласовать ξ»:

uᵢ = −k Σⱼ aᵢⱼ (ξᵢ − ξⱼ) = −k (L ξ)ᵢ.

Центр формации — среднее начальных ξ: где соберётся фигура, заранее не задано.

**Сохранение связности** (Ji, Egerstedt, 2007). Консенсус по текущему графу может порвать рёбра: робот, у которого много соседей с одной стороны, уезжает от единственного соседа с другой. Если управлять только по рёбрам начального графа с весом

w(d) = (2R − d) / (R − d)²,

который неограниченно растёт при d → R, «энергия» V = Σ ∫ w — функция Ляпунова, не допускающая выхода длины ребра на R. Цена: закон не добавляет новых рёбер и не использует связи, появившиеся по ходу движения.

**W-MSR** (LeBlanc, Zhang, Koutsoukos, Sundaram, 2013; §16.8.3). Нормальный агент отбрасывает до F соседних значений больше своего и до F значений меньше своего, остальные усредняет. Если граф (2F+1)-робастен, нормальные агенты согласуются внутри диапазона своих начальных значений при любом поведении не более чем F злонамеренных соседей.

## 3. Базовый маршрут

### Шаг 1. Лапласиан и λ₂

Реализуйте `laplacian` и `algebraic_connectivity`. Две строки кода каждая — если у вас больше, скорее всего, вы считаете что-то лишнее.

- Собственные числа — `np.linalg.eigvalsh` (для симметричных матриц: вещественные и отсортированные). `np.linalg.eig` даст комплексные числа с мнимой частью порядка 10⁻¹⁷ и неупорядоченные.
- Для графа из одной вершины λ₂ не определена — верните 0.0.
- Из-за округления λ₂ несвязного графа может получиться −1·10⁻¹⁶. Отрицательных значений не возвращайте.

Проверка: `python -m unittest tests.test_pr1.Step1Laplacian -v`.

**В отчёт:** вычислите вручную лапласиан и λ₂ пути из 4 вершин (ответ: λ₂ = 2 − √2 ≈ 0,586) и сравните с программой.

### Шаг 2. Дискретный консенсус

Реализуйте `max_consensus_step` и `consensus_step`.

- `consensus_step` должен работать и для вектора (N,), и для матрицы (N, d) — `L @ x` делает это сам.
- **Синхронность.** Все агенты обновляются по значениям *предыдущего* шага. Цикл `for i: x[i] += …`, меняющий x на месте, — это другой алгоритм (асинхронный, Гаусс — Зейдель): среднее не сохраняется, результат зависит от порядка агентов. Это блокирующая ошибка.

Проверка: `python -m unittest tests.test_pr1.Step2Consensus -v`.

**В отчёт:** докажите в две строки, что Σ xᵢ(k+1) = Σ xᵢ(k) (подсказка: 1ᵀL = 0ᵀ).

### Шаг 3. Формация

Реализуйте `formation_velocity` через `laplacian` и замену ξ = p − δ — одна-две строки. Тест `Step3Formation` проверяет не только сборку фигуры, но и то, что центр формации равен среднему начальных ξ.

### Шаг 4. Сохранение связности

Реализуйте `connectivity_weight` и `rendezvous_velocity`.

- Рёбра берутся из **начального** графа `A_init`, а не текущего.
- Вес при d ≥ R — 0. Если начальное ребро всё же достигло R (слишком большой шаг интегрирования), это сигнал уменьшить dt, а не «чинить» вес.
- Типовая ошибка: знак. uᵢ = −k Σ w (pᵢ − pⱼ) тянет робота *к* соседу.

Проверка: `python -m unittest tests.test_pr1 -v` — проходят все классы, кроме `Step5WMSR` (если не делаете ★1).

```bash
python webots/run.py run pr1_formation --seed <номер бригады>
python webots/run.py run pr1_formation_fail --seed <номер бригады>
python webots/run.py show pr1_formation --seed <номер бригады>     # посмотреть глазами
```

**Что происходит.** Шесть e-puck стоят в случайных местах (начальный граф связи с запасом связен). Каждый робот 15 раз в секунду рассылает по радио свою позицию (дальность 0,7 м) и считает скорость по закону `formation_velocity` **только по соседям, которых слышал за последние 0,5 с**, — «звезда» с самим собой в центре. Скорость переводится в скорости колёс через вынесенную точку (`sim.unicycle_from_velocity`). Позицию робот знает от GPS — идеальная локализация, это упрощение.

**Итог** — `reports/webots/pr1_formation.json`: `formation_error_final` — ошибка формы в конце, м; `formation_time_2cm` — когда ошибка впервые стала меньше 2 см; `min_distance` — наименьшее расстояние между центрами роботов; `close_approaches` — сколько раз центры сблизились меньше диаметра e-puck (0,074 м), то есть было касание.

**В отчёт:**

1. Траектории из `pr1_formation.csv` (постройте сами: столбцы `t, robot, x, y`) и график ошибки формы во времени.
2. Сравнение с Э2 при нулевых потерях: во сколько раз медленнее и почему. Учтите: ограничение скорости 0,1 м/с, неголономный привод (робот сначала разворачивается), граф связи меняется при движении, коэффициент усиления.
3. Касания: сколько, когда, почему закон формации их не предотвращает.
4. `pr1_formation_fail`: что происходит после отказа робота 2 на 20-й секунде; почему ошибка формы (она считается по всем шести роботам) не уходит в ноль и что на самом деле делают остальные пять.
