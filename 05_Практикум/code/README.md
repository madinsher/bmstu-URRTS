# Код практикума УРРТС

Учебная библиотека `urrts`, приёмочные тесты, скрипты экспериментов и сцены Webots для шести практикумов.

## Установка

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
```

Проверка, что всё на месте (общие модули должны пройти сразу):

```bash
python -m unittest tests.test_common -v
```

Для сцен Webots дополнительно нужен [Webots R2025a](https://cyberbotics.com/). Отдельно ставить ничего не надо: контроллеры роботов импортируют ту же библиотеку `urrts`.

## Что где

| Путь | Назначение |
|---|---|
| `urrts/graph.py`, `urrts/sim.py`, `urrts/plot.py` | общие модули: граф связи, симулятор группы, графики — **готовы** |
| `urrts/pr1_consensus.py` … `urrts/pr6_safety.py` | модули практикумов — **здесь пишет бригада** |
| `tests/test_prN.py` | приёмочные тесты: по классу на шаг (`Step1…`, `Step2…`) |
| `experiments/prN.py` | эксперименты для отчёта: таблицы CSV и рисунки PNG в `reports/prN/` |
| `webots/run.py` | сцены Webots: генерация мира, прогон без отрисовки, показ |
| `webots/controllers/urrts_epuck` | контроллер e-puck: робот знает только себя и соседей по радио |
| `webots/controllers/urrts_supervisor` | супервизор сцены: журнал позиций, метрики, внесение отказов |

## Шаги бригады

Места, которые пишет бригада, размечены в коде:

```python
# >>> STUDENT ПР1-шаг2: что сделать
raise NotImplementedError("ПР1-шаг2: consensus_step")
# <<< STUDENT
```

Строку `raise NotImplementedError` заменяют своей реализацией. Всё, что между маркерами, — ваше; сигнатуры функций и строки документации не меняйте: по ним работают тесты, эксперименты и контроллеры Webots.

| Практикум | Шаги | Модуль | Тесты |
|---|---|---|---|
| ПР1. Консенсус и формация | 1–5 (5 — ★) | `pr1_consensus.py` | `tests/test_pr1.py` |
| ПР2. Роевое поведение | 1–4 | `pr2_swarm.py` | `tests/test_pr2.py` |
| ПР3. Распределение задач | 1–4 | `pr3_allocation.py` | `tests/test_pr3.py` |
| ПР4. Многоагентный поиск путей | 1–5 | `pr4_mapf.py` | `tests/test_pr4.py` |
| ПР5. Покрытие и оценивание | 1–5 (5 — ★) | `pr5_coverage.py` | `tests/test_pr5.py` |
| ПР6. Безопасность группы | 1–5 | `pr6_safety.py` | `tests/test_pr6.py` |

Тесты одного шага:

```bash
python -m unittest tests.test_pr1.Step2Consensus -v
```

Все тесты практикума:

```bash
python -m unittest tests.test_pr1 -v
```

До выполнения шага его тесты падают с `NotImplementedError` — это нормально.

## Эксперименты

После того как все тесты практикума проходят:

```bash
python experiments/pr1.py --seed <номер бригады>
```

Таблицы печатаются в консоль и сохраняются в `reports/pr1/*.csv`, рисунки — в `reports/pr1/*.png`. Ключ `--quick` уменьшает объём, чтобы быстро убедиться, что всё запускается. Зерно `--seed` = номер бригады: у каждой бригады свои начальные условия, свои числа и свои рисунки.

## Сцены Webots

```bash
python webots/run.py list                          # сценарии
python webots/run.py run pr6_swap --seed 3         # прогон без отрисовки, итог — в reports/webots
python webots/run.py show pr6_swap --seed 3        # открыть в Webots и смотреть
```

| Сценарий | Практикум | Что происходит |
|---|---|---|
| `pr1_formation` | ПР1 | 6 e-puck собирают шестиугольник, зная только соседей по радио (дальность 0,7 м) |
| `pr1_formation_fail` | ПР1 | то же, робот 2 отказывает на 20-й секунде |
| `pr4_warehouse` | ПР4 | 6 e-puck исполняют план CBS на складе по графу зависимостей |
| `pr5_coverage` | ПР5 | 8 e-puck расходятся по области с очагом важности |
| `pr6_swap` | ПР6 | 8 e-puck меняются местами через центр с барьерными функциями |
| `pr6_swap_mute` | ПР6 | то же, робот 0 молчит в эфире с 3-й по 40-ю секунду |

При **первом запуске** Webots скачивает модель e-puck и текстуры: сцена стартует дольше обычного, и пока она грузится, контроллеры не подключаются. Повторные запуски идут из кэша.

Webots не запускает контроллеры из путей с кириллицей или пробелами. Поэтому `run.py` копирует каталог `code` во временную папку (`%TEMP%\urrts_webots` или путь из переменной `URRTS_WORK`), запускает там и копирует журналы обратно в `reports/webots/`. Какой Python запускает контроллеры, `run.py` прописывает сам — тот же, которым запущен скрипт.

Итог прогона — `reports/webots/<сценарий>.json`: наименьшая дистанция между центрами роботов, число сближений ближе диаметра e-puck (0,074 м), время прибытия, ошибка формы. Журнал позиций с шагом 0,1 с — `reports/webots/<сценарий>.csv`.
